# Week 3 Day 3 - SQL Aggregation, Subqueries & CTEs

Concept Check
1. What is the difference between WHERE and HAVING?
Where is used to filter columns and after that we use group by and to filter groups we will use HAVING.

2. When would you use a correlated subquery instead of a JOIN?
A correlated subquery is used when the inner query depends on each row of the outer query. It runs once for every row of the outer query, while a JOIN simply combines data from related tables.

3. What is a CTE, and why is it more readable than a nested subquery?
A CTE (Common Table Expression) is a temporary result set created using the WITH keyword. It makes complex queries easier to read and understand because the logic is divided into smaller parts, while nested subqueries become difficult to read when many queries are written inside each other.

4. Explain the difference between RANK() and DENSE_RANK().
Rank() allocates rank to the rows and if there two same enteries like same score then it will skip next rank and move to third while dense_rank() do not miss rank if there are same scores then it will mark third as second rank.

5. What does PARTITION BY do differently from GROUP BY?
Group by collapses the rows and show only one result per group while partition by do not collapses the rows but ig make groups and show all rows.

6. Can a subquery return multiple rows? What operator would you use in that case?
Yes, a subquery can return multiple rows. In that case, we usually use the IN,ANY,ALL operators to compare multiple values.

7. Give an example of when CASE WHEN is useful inside an aggregate function.
CASE WHEN is useful inside aggregate functions when we want to calculate values based on a condition. For example, we can count only active customers or calculate the total sales of a specific category using SUM() with CASE WHEN.


### Subquery

Use a subquery when the result of one query is needed inside another query for comparison or filtering.

### CTE (WITH)

Use a CTE to break a complex query into smaller and more readable parts. It also helps reuse intermediate results.

### Window Function

Use window functions when you need ranking, row numbering or calculations while keeping all rows in the result.
